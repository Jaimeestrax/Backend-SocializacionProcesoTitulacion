# Backend-Socializacion_Proceso_Titulacion
Este repositorio contiene el proyecto desarrollado en NodeJS con Express y MongoDB para poner a disposición una API REST

## Tecnologías
- Node.js: v22.22.2
- Express: v4.22.1
- MongoDB Community: v8.2.1
- Mongoose: v9.4.1

## Scripts
- `npm run dev o node --run dev`: Inicia el servidor con nodemon
- `npm start`: Inicia en producción
